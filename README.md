# Codex + ChatGPT Pro Answers

这是一个公开的“双回答”存档仓库。同一个问题会分别交给 Codex 和 Edge 中实际显示为 **Pro** 的 ChatGPT 模型回答，再以 Markdown 形式发布。

每篇记录包含：

- 原始问题与必要的公开上下文
- Codex 回答
- ChatGPT Pro 原始回答
- 模型标识、时间和上下文差异说明

记录位于 [`answers/`](answers/) 目录。

这里的内容对所有人可见。密码、令牌、Cookie、私人身份信息、未获授权的专有代码以及其他敏感内容不会被发送到浏览器模型或提交到本仓库；遇到此类内容时，发布流程会暂停并请求确认或脱敏版本。
